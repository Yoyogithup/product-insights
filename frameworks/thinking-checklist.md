# PM 思考清单

> 体验 AI 产品时的思考框架，帮助你从 PM 视角深度分析产品

---

## 🎯 产品定位思考

### 1. 用户价值
- [ ] 这个产品解决了什么核心问题？
- [ ] 目标用户是谁？用户画像清晰吗？
- [ ] 用户为什么要用这个产品而不是竞品？
- [ ] 产品的核心价值主张是什么？

### 2. 市场定位
- [ ] 在 AI 产品矩阵中的位置？（通用 vs 垂直）
- [ ] 与竞品的差异化在哪里？
- [ ] 市场切入点选择是否合理？
- [ ] 是先发优势还是后发制人？

---

## 💼 商业模式思考

### 1. 盈利模式
- [ ] 如何赚钱？（订阅/按量/免费增值）
- [ ] 定价策略合理吗？
- [ ] 付费转化路径设计如何？
- [ ] 成本结构是否可持续？

### 2. 增长策略
- [ ] 如何获取新用户？
- [ ] 留存策略是什么？
- [ ] 有网络效应吗？
- [ ] 护城河在哪里？

---

## 🎨 产品设计思考

### 1. 功能设计
- [ ] 核心功能是否聚焦？
- [ ] 功能优先级排列合理吗？
- [ ] 有没有过度设计或缺失功能？
- [ ] AI 能力与产品功能融合度如何？

### 2. 交互体验
- [ ] 新手引导是否友好？
- [ ] 核心操作路径是否顺畅？
- [ ] 信息架构是否清晰？
- [ ] 错误处理和反馈机制如何？

### 3. 视觉设计
- [ ] 界面美观度如何？
- [ ] 品牌调性与目标用户是否匹配？
- [ ] 视觉层级是否清晰？
- [ ] 设计是否有记忆点？

---

## ⚙️ 技术能力思考

### 1. AI 能力表现
- [ ] 模型理解准确度如何？
- [ ] 输出质量稳定吗？
- [ ] 响应速度能否满足需求？
- [ ] 上下文记忆能力如何？

### 2. 技术实现
- [ ] 技术选型是否合理？
- [ ] 性能优化做得如何？
- [ ] 有没有明显的技术瓶颈？
- [ ] 可扩展性如何？

---

## 📊 数据指标思考

### 1. 关键指标
- [ ] 这个产品的北极星指标应该是什么？
- [ ] 如何衡量产品成功？
- [ ] 哪些数据需要重点关注？
- [ ] 数据埋点设计合理吗？

### 2. 用户行为
- [ ] 用户的典型使用路径是什么？
- [ ] 流失点可能在哪里？
- [ ] 用户活跃度如何提升？
- [ ] 付费转化的关键节点在哪？

---

## 🚀 产品策略思考

### 1. 竞争策略
- [ ] 面对竞品的优势和劣势？
- [ ] 如何构建差异化？
- [ ] 竞争壁垒是什么？
- [ ] 如何应对大厂进入？

### 2. 发展方向
- [ ] 下一步应该做什么？
- [ ] 产品的天花板在哪里？
- [ ] 可能的延展方向有哪些？
- [ ] 3 年后这个产品会是什么样？

---

## ⚠️ 风险思考

### 1. 产品风险
- [ ] 产品依赖性风险？（如依赖某个大模型）
- [ ] 技术风险？
- [ ] 合规风险？
- [ ] 用户隐私和数据安全？

### 2. 市场风险
- [ ] 市场需求变化风险？
- [ ] 竞争加剧风险？
- [ ] 政策监管风险？
- [ ] 技术迭代风险？

---

## 💡 创新启发

### 1. 亮点提炼
- [ ] 这个产品最让我惊喜的 3 点是什么？
- [ ] 有哪些值得借鉴的设计？
- [ ] 哪些做法可以应用到我的工作中？

### 2. 改进机会
- [ ] 如果我是这个产品的 PM，我会优先改什么？
- [ ] 有哪些明显的机会点被忽略了？
- [ ] 如何做能让这个产品更好？

---

## 📝 使用建议

**体验前：** 
- 快速浏览清单，明确关注点
- 选择 3-5 个最关心的维度重点思考

**体验中：**
- 边体验边记录思考
- 不必每个问题都回答，抓重点

**体验后：**
- 回顾清单，补充遗漏的思考
- 总结最有价值的 3-5 个洞察

---

*这个清单是思考工具，不是考试题。根据实际情况灵活使用！*
