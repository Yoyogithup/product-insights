# 📊 Product Insights | AI 产品体验分析

> 记录 AI 产品体验、分析与思考，提升产品体感

## 👋 关于本项目

这个仓库用来记录我对 AI 产品的体验分析，通过系统化的体验和思考，提升对 AI 产品的理解和感知能力。

## 📁 内容结构

### 📝 [产品清单](./product-list/)
待体验和已体验的 AI 产品清单，按分类和优先级组织

### 🎯 [体验框架](./frameworks/)
产品体验的分析模板和思考框架

### 📊 [体验报告](./reports/)
单个产品的详细体验分析报告

### 🔍 [横向对比](./comparisons/)
同类产品的对比分析

### 💡 [洞察思考](./insights/)
从体验中提炼的洞察和思考

### 📚 [使用文档](./docs/)
工作流程和使用说明

## 🎯 目标

- 系统化体验主流 AI 产品
- 建立产品评估框架
- 提升产品体感和判断力
- 积累产品洞察

## 🚀 工作流程

1. 选择产品 → 查看待体验清单
2. 体验分析 → 使用框架模板
3. 记录整理 → 形成体验报告
4. 横向对比 → 同类产品对比
5. 提炼洞察 → 总结思考
