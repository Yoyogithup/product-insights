# 📊 Product Insights | 产品洞察

> 记录产品调研、竞品分析和行业洞察

## 👋 关于本项目

这是一个持续更新的产品调研和洞察库，记录我在产品工作中的研究成果、竞品分析和行业观察。

## 📁 目录结构

```
product-insights/
├── templates/       # 调研模板
├── reports/         # 调研报告
└── insights/        # 洞察总结
```

## 🎯 内容分类

### 📋 [调研模板](./templates/)
标准化的调研模板，提高调研效率

### 📊 [调研报告](./reports/)
按时间组织的调研报告，包含竞品分析、市场分析、用户调研等

### 💡 [洞察总结](./insights/)
从调研中提炼的关键洞察和行业趋势

## 💡 如何使用

1. **使用模板**：从 templates 目录选择合适的模板开始调研
2. **保存报告**：完成的调研报告保存在 reports 目录，按年份/月份组织
3. **沉淀洞察**：将有价值的洞察提炼到 insights 目录

## 📝 内容规范

### 文件命名
- 报告：`YYYY-MM-产品名称-调研类型.md`
- 洞察：`主题-关键词.md`

### 文件格式
- 主要使用 Markdown 格式便于版本管理和在线查看
- 复杂图表和完整报告可以附带 PDF 版本

## 🔖 标签说明

为每个报告添加合适的标签，方便分类查找：
- `#竞品分析`
- `#用户调研`
- `#市场分析`
- `#行业趋势`
- `#功能评测`
