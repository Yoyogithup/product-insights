## 👋 关于本项目

作为产品经理，我通过这个仓库**系统化地体验和分析 AI 产品**。

不仅仅是简单试用，而是：

- 🎯 从 PM 视角深度分析产品定位、商业模式、用户价值
- 📊 建立标准化的体验框架和评估标准
- 🔍 横向对比同类产品，提炼差异化优势
- 💡 积累产品洞察，提升对 AI 产品的判断力

## 🎨 体验框架

### 核心工具

#### 1️⃣ [体验分析模板](./frameworks/experience-template.md)

通用的产品体验记录框架，包含：

- 基本信息、第一印象
- 核心功能体验（详细测试场景）
- 深度使用（综合任务）
- 横向对比、产品分析
- 体感与思考、打分结论

#### 2️⃣ [PM 思考清单](./frameworks/thinking-checklist.md)

从产品经理视角的 8 大思考维度：

- 🎯 产品定位（用户价值、市场定位）
- 💼 商业模式（盈利模式、增长策略）
- 🎨 产品设计（功能、交互、视觉）
- ⚙️ 技术能力（AI 能力、技术实现）
- 📊 数据指标（关键指标、用户行为）
- 🚀 产品策略（竞争策略、发展方向）
- ⚠️ 风险思考（产品风险、市场风险）
- 💡 创新启发（亮点提炼、改进机会）

#### 3️⃣ 分类补充关注点

不同产品类型有特定的评估重点：

- **AI 对话类**：对话理解、多轮记忆、推理能力、中文能力、可信度
- **AI + 业务类**：业务理解、智能推荐、传统对比、业务价值、流程融合
- **AI + 工具类**：功能融合、效率提升、学习成本、准确性、性价比

> 📖 详细说明：[frameworks/README.md](./frameworks/README.md)

## 🚀 快速开始

### 💡 如何使用这个仓库？

#### 作为体验者

1. **查看产品清单** → [product-list/README.md](./product-list/README.md)
2. **选择感兴趣的产品**
3. **复制体验模板** → [frameworks/experience-template.md](./frameworks/experience-template.md)
4. **边体验边记录**，重点记录有感觉的点
5. **参考思考清单** → [frameworks/thinking-checklist.md](./frameworks/thinking-checklist.md)

#### 作为学习者

- 浏览 [reports/](./reports/) 查看已完成的体验报告
- 学习如何系统化地分析产品
- 参考思考框架提升产品思维
