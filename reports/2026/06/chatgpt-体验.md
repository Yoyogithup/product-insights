## 核心功能体验

### 功能 1：对话理解与回答

#### 场景 1.1：简单对话
**使用场景：** 日常问答、信息查询

**测试问题：**

**问题 1（事实性）：** 
```
什么是产品经理的北极星指标？请举 2 个具体例子。
```
**评价标准：**
- ⭐⭐⭐⭐⭐：解释清晰准确 + 例子恰当具体
- ⭐⭐⭐⭐：解释正确，例子一般
- ⭐⭐⭐：基本正确，但不够具体
- ⭐⭐：有错误或不够准确
- ⭐：答非所问

**问题 2（模糊意图）：**
```
我想做一个关于年轻人的产品，有什么建议吗？
```
**评价标准：**
- ⭐⭐⭐⭐⭐：主动澄清（问目标用户、产品类型等），给出结构化建议
- ⭐⭐⭐⭐：直接给建议，但建议质量高
- ⭐⭐⭐：给出建议，但比较泛泛
- ⭐⭐：建议不实用
- ⭐：答非所问

**问题 3（需要推理）：**
```
小红书的日活 2 亿，月活 3 亿，这说明了什么？
```
**评价标准：**
- ⭐⭐⭐⭐⭐：准确计算 DAU/MAU，分析用户粘性，给出合理推论
- ⭐⭐⭐⭐：计算正确，分析合理
- ⭐⭐⭐：能做基本分析
- ⭐⭐：分析有误
- ⭐：无法理解问题

### 功能 2：多轮对话记忆

#### 场景 2.1：上下文连贯性测试
**使用场景：** 持续深入讨论一个话题

**测试对话流程：**

**第 1 轮（建立上下文）：**
```
我在做一个面向大学生的二手交易平台，目标是校园内的闲置物品交易。
目前遇到的问题是：用户发布商品后，很少有人咨询和购买。
```

**第 2 轮（基于上下文提问）：**
```
你觉得可能是什么原因？
```

**第 3 轮（测试记忆）：**
```
针对我刚才说的问题，如果要做 AB 测试，应该测什么？
```
*评价点：是否记得"用户发布后很少人咨询购买"这个问题*

**第 4-5 轮（继续深入）：**
```
第 4 轮：那具体怎么设计这个 AB 测试方案？
第 5 轮：如果 A 方案效果好，下一步应该做什么？
```

**第 6-8 轮（测试长期记忆）：**
```
第 6 轮：回到我最开始说的问题，除了 AB 测试，还有其他快速验证的方法吗？
第 7 轮：这些方法中，哪个最适合大学生群体？
第 8 轮：为什么你觉得这个方法适合大学生？
```
*评价点：是否还记得"目标用户是大学生"、"校园内闲置交易"*

**第 9-10 轮（挑战记忆边界）：**
```
第 9 轮：如果我的平台从校园扩展到全社会，之前的方案还适用吗？
第 10 轮：那对于我最初说的大学生场景，你能总结一下完整的解决方案吗？
```

**评价标准：**
- ⭐⭐⭐⭐⭐：10 轮全部记得，上下文连贯，能区分不同阶段的信息
- ⭐⭐⭐⭐：能记住 6-8 轮的信息，偶有遗忘但不影响对话
- ⭐⭐⭐：能记住 4-5 轮，超过 5 轮开始遗忘
- ⭐⭐：只能记住 2-3 轮，经常需要重复
- ⭐：基本无记忆，每轮都像新对话

### 功能 3：推理能力

#### 场景 3.1：逻辑推理
**使用场景：** 解决逻辑问题、因果分析

**测试问题：**

**问题 1（经典逻辑题）：**
```
有 3 个开关和 3 个灯泡在不同房间。你只能进入灯泡房间一次。
如何确定每个开关对应哪个灯泡？
```
**评价标准：**
- ⭐⭐⭐⭐⭐：给出正确方案（利用温度），推理过程清晰
- ⭐⭐⭐⭐：方案正确，但解释不够清晰
- ⭐⭐⭐：思路对，但方案不完整
- ⭐⭐：思路错误但有尝试推理
- ⭐：无法理解或放弃

**问题 2（产品因果分析）：**
```
某视频 App 在改版后，DAU 下降了 15%，但用户时长增加了 20%。
可能的原因是什么？应该如何分析？
```
**评价标准：**
- ⭐⭐⭐⭐⭐：多维度分析（用户分层、功能变化、竞品等），给出分析框架
- ⭐⭐⭐⭐：能列出 3+ 个可能原因，逻辑合理
- ⭐⭐⭐：能想到 1-2 个原因
- ⭐⭐：原因不合理
- ⭐：答非所问

**问题 3（多步推理）：**
```
如果你是拼多多的 PM，老板要求你在 3 个月内让新用户次月留存率提升 10%。
你会怎么做？（请给出完整的思考过程）
```
**评价标准：**
- ⭐⭐⭐⭐⭐：完整的推理链（现状分析→流失原因→解决方案→优先级→验证方式）
- ⭐⭐⭐⭐：有结构化思考，方案可行
- ⭐⭐⭐：能给出方案，但缺少推理过程
- ⭐⭐：方案不可行
- ⭐：答非所问

**实际体验：**
- 问题 1 输入/输出/评分：
- 问题 2 输入/输出/评分：
- 问题 3 输入/输出/评分：
- 推理过程是否清晰：
- 结论是否正确：
- 整体评价：⭐⭐⭐⭐⭐ + 理由

- ⭐⭐⭐⭐⭐：两个答案都正确，计算过程清晰

## 深度使用（综合任务测试）

### 任务 1：产品分析完整流程
**任务描述：** 从 0 到 1 完成一个产品分析任务，测试综合能力

**具体任务提示词：**
```
我想做一个完整的产品分析，请按以下步骤帮我完成：

第 1 步：分析小红书的核心价值
- 目标用户是谁？
- 解决了什么核心问题？
- 核心价值主张是什么？

第 2 步：竞品对比分析
- 对比小红书、抖音、微博三个产品
- 从内容形态、用户群体、商业化三个维度对比
- 指出小红书的差异化优势

第 3 步：提出 3 个优化建议
- 针对小红书当前的问题或机会
- 建议要具体可落地
- 说明优先级和理由

第 4 步：为第一个建议设计验证方案
- MVP 方案是什么？
- 如何验证效果？
- 关键数据指标是什么？

请一步一步完成，每步等我确认后再继续。
```

**评价标准：**
- ⭐⭐⭐⭐⭐：分析深入专业，建议可落地，验证方案完整，像专业 PM 的输出
- ⭐⭐⭐⭐：分析合理，建议可行，方案基本完整
- ⭐⭐⭐：能完成任务，但深度不够
- ⭐⭐：分析浅显，建议不实用

### 任务 2：多轮深度讨论
**任务描述：** 就一个复杂话题进行 15-20 轮的深度讨论，测试长对话能力

**话题：** 如何提升某个产品的用户留存率

**讨论框架建议：**

**开场（第 1-2 轮）：** 设定场景，介绍产品背景
**深入分析（第 3-7 轮）：** 讨论流失原因、数据分析
**方案探讨（第 8-12 轮）：** 提出解决方案、评估优先级
**细化执行（第 13-17 轮）：** 讨论具体执行、资源需求
